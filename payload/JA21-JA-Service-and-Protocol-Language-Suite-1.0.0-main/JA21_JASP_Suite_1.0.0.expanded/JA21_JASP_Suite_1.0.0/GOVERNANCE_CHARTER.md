# Governance Charter

The suite is governed by five publication lenses:

- **SOPHIA:** semantic and policy consistency.
- **CHARLOTTE:** reconstruction, compatibility, and provenance closure.
- **LANDON:** executable workflow, runtime behavior, and diagnostics.
- **Professor:** pedagogy, terminology, proof obligations, and assessment.
- **Podium:** visual hierarchy, navigability, and release communication.

No lens may convert modeled corpus expectations into claims of native execution. Changes must preserve source provenance, deterministic manifests, explicit network authority, fail-closed safety, and versioned evidence.
